## Feather Task Manager 2026.9.6

Nuclear Zombie가 Sysinternals RAMMap의 메모리 비우기(Empty) 명령을 모두 지원하고, 리소스 모니터와 새 작업 실행을 다듬었습니다.

- **Nuclear Zombie = RAMMap의 Empty 메뉴 전부:** 작업 집합, **시스템 작업 집합**(새로 추가), 수정된 페이지 목록, 대기 목록, **우선순위 0 대기 목록**(새로 추가)을 비울 수 있습니다. Feather가 관리자 권한이면 작업 집합을 RAMMap과 같이 모든 프로세스에서 한 번에 비우고, 일반 권한이면 UAC 없이 열 수 있는 프로세스만 정리합니다. 관리자 단계는 UAC 한 번으로 정해진 순서대로 실행하고, 대기 캐시 전체 비우기와 우선순위 0만 비우기는 함께 켤 수 없습니다.
- **리소스 모니터:**
  - 메뉴(오른쪽 클릭, 갱신 주기 등)와 프로세스 끝내기 확인 창이 Windows 기본 메뉴·메시지 상자 대신 Feather 디자인으로 열립니다. 확인 창은 "외 N개"와 Windows 프로세스 경고를 메인 창처럼 보여 줍니다.
  - 선택이 행 위치가 아니라 대상(프로세스, 서비스, 모듈, 파일, 연결)을 따라가고, 새로 고쳐도 행 순서가 흔들리지 않습니다.
  - 값이 들어오지 않던 열(파일 응답 시간, TCP 지연)과 빈 핸들 패널을 없앴습니다.
  - 메뉴를 여는 동안에도 파일·연결 추적이 끊기지 않고, 설정이 바뀔 때만 다시 수집합니다. 오류와 상태 문구가 한국어로 표시됩니다.
  - 제목 표시줄(오른쪽 클릭 시스템 메뉴, Alt 키)과 창 전환 후 포커스가 메인 창과 똑같이 동작합니다.
- **새 작업 실행:** `wt`, `winget` 같은 Microsoft Store 앱 별칭을 실행할 수 있고, 잘못된 프로그램은 창을 닫기 전에 오류를 보여 줍니다. 프로그램 확인은 UI 스레드 밖에서 합니다.
- **표:** 모든 표의 가로 스크롤바가 Feather 디자인으로 바뀌었습니다. `Ctrl+Shift+C` 열 메뉴에서 표시된 모든 열을 키보드로 옮기고 너비를 바꾸거나 숨길 수 있습니다. Shift+F10과 메뉴 키는 항상 선택한 행의 메뉴를 엽니다.
- 일시정지한 서비스 화면은 리소스 모니터가 새 목록을 받아도 그대로 유지됩니다.
- 사용할 수 없는 온도 센서를 메뉴를 열 때마다 다시 조회하지 않습니다.
- [개인정보 처리방침](https://github.com/Hardt-LLC/FeatherTaskManager/blob/v2026.9.6/PRIVACY.md)과 [보안 문서](https://github.com/Hardt-LLC/FeatherTaskManager/blob/v2026.9.6/SECURITY.md)에 시스템 작업 집합 비우기와 새 관리자 도우미 인수를 반영했습니다.

자동 검사 **353개 통과**, 형식·Clippy·배포 스크립트 검사를 통과했습니다. UI 배치 검사는 이제 기대값을 화면 배율에 맞춰 계산합니다. Nuclear Zombie의 관리자 단계(실제 메모리 비우기), 관리자 권한 새 작업, 탐색기 다시 시작, 실제 설치·제거는 별도 수동 확인 범위입니다.

**Setup-x64.exe**는 설치용, **Portable-x64.exe**는 바로 실행하는 파일입니다. 앱·설치·제거 프로그램은 Azure Artifact Signing / **HARDT**로 서명하고 타임스탬프를 검증했습니다. 체크섬은 `SHA256SUMS.txt`를 참고하세요.

### English

- **Nuclear Zombie covers RAMMap's whole Empty menu:** working sets, the **system working set** (new), the modified page list, the standby list and the **priority 0 standby list** (new). Elevated, Feather empties every process's working set at once, like RAMMap; otherwise it trims the processes it can open, without UAC. The administrator steps run in a fixed order behind one UAC prompt, and clearing the whole standby cache and priority 0 only cannot be combined.
- **Resource Monitor:**
  - Its menus (right-click, refresh rate and others) and its end-process confirmation now use Feather's own design instead of native menus and message boxes; the confirmation shows "and N more" and the Windows-process warning like the main window.
  - Selection follows its target (process, service, module, file, connection) instead of the row position, and rows keep their order between refreshes.
  - Columns that never had data (file response time, TCP latency) and the empty handles panel are gone.
  - File and connection tracing keeps running while a menu is open, and data is re-collected only when a setting changes. Errors and status text appear in Korean too.
  - The title bar (right-click system menu, Alt) and focus after switching windows behave like the main window.
- **Run new task:** Microsoft Store app aliases such as `wt` and `winget` run, an invalid program is reported before the dialog closes, and programs are checked off the UI thread.
- **Tables:** every table's horizontal scrollbar uses Feather's design. From `Ctrl+Shift+C`, every shown column can be moved, resized or hidden from the keyboard. Shift+F10 and the menu key always open the selected row's menu.
- A paused Services page stays as it is while the Resource Monitor receives new lists.
- Unavailable temperature sensors are no longer queried again whenever a menu opens.
- The [privacy policy](https://github.com/Hardt-LLC/FeatherTaskManager/blob/v2026.9.6/PRIVACY.md) and [security notes](https://github.com/Hardt-LLC/FeatherTaskManager/blob/v2026.9.6/SECURITY.md) describe emptying the system working set and the new administrator helper arguments.

353 automated tests passed, plus format, Clippy and release-script checks; UI layout tests now derive their expected sizes from the display scaling. Nuclear Zombie's administrator steps (actually emptying memory), elevated Run new task, Explorer restart and real install/uninstall remain manual verification scope.

App, installer and embedded uninstaller are Azure Artifact Signing signed by **HARDT** and timestamped. See `SHA256SUMS.txt`.
