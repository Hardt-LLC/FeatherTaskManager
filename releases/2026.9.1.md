## Feather Task Manager 2026.9.1

가벼운 Rust/Win32 작업 관리자에 프로세스 트리, 영어 UI와 설치 프로그램을 추가했습니다.

- 단축키 안내의 키·설명 열 정렬 개선
- 프로세스 **목록 / 트리** 전환, 가지 접기·펼치기, 검색 시 상위 경로 표시
- **트리 끝내기 / Shift+Delete**: 확인한 대상의 신원을 재검사한 후 자식부터 종료 요청
- **설정 → 한국어 / English** 즉시 전환, 사용자별 언어 저장
- 설치·업데이트·제거 프로그램과 시작 메뉴/선택적 바탕 화면 바로가기
- `yyyy.m.x` 버전 체계 도입. 같은 달의 다음 버전은 `2026.9.2`

**Setup-x64.exe**는 설치 파일, **Portable-x64.exe**는 설치 없이 실행하는 파일입니다. ZIP에는 포터블 앱, 설명서와 작업 관리자 연결 복구 스크립트가 포함됩니다. Windows 10/11 x64를 지원합니다.

앱·설치 프로그램·내장 제거 프로그램은 **Azure Artifact Signing / HARDT**로 서명하고 타임스탬프를 검증했습니다. 해시는 `SHA256SUMS.txt`에서 확인하세요.

트리 종료는 확인할 때 캡처한 대상만 포함하며 이후 생성된 자식을 계속 추적하지 않습니다. 저장하지 않은 작업은 사라질 수 있습니다. 다른 앱이나 서비스의 자동 재시작까지 막지는 않습니다. 설치만으로 Windows 작업 관리자 연결을 바꾸지 않습니다. 대체는 앱 설정에서 선택하고, 파일을 수동 삭제하기 전에는 연결을 복원하세요.

자동 검사 **66개 통과**. 실제 관리자 설치·제거와 Ctrl+Alt+Delete 보안 화면 실행은 별도 수동 확인 범위입니다.

### English

- Aligned shortcut and description columns.
- Switch between flat process lists and trees; expand/collapse branches and keep ancestor context when searching.
- End a confirmed process tree, children first, with PID/creation-time and protected-process checks before termination.
- Switch Korean/English instantly in Settings; save the preference per user.
- Installer with shortcuts, updates and guarded uninstall; portable EXE remains available.
- Calendar versioning: `yyyy.m.x`, with an incrementing monthly release number.

Choose **Setup-x64.exe** to install or **Portable-x64.exe** to run directly. Windows 10/11 x64. App, installer and embedded uninstaller are Azure Artifact Signing signed by **HARDT** and timestamped. See `SHA256SUMS.txt` for checksums.

Tree termination targets only the captured processes; new descendants and automatic restarts are not intercepted. Installation does not automatically replace Windows Task Manager. Enable or restore that association through Settings. 66 automated checks passed; real elevated installation/uninstallation and the secure-attention launch path still require manual verification.
