## Feather Task Manager 2026.9.2 — 보안 업데이트

2026.9.1의 로컬 권한 경계와 실행·설치 경로를 검토하고 보안 문제 4건을 수정했습니다.

- 포터블 파일을 관리자 권한으로 복사하던 경로를 제거했습니다. 작업 관리자 대체 설정은 검증된 Program Files 설치 파일만 사용합니다.
- 실행 파일 옆에 놓인 DLL을 정적 의존성으로 불러오지 않도록 시스템 DLL 검색 경로를 제한했습니다.
- 시작 앱 상태·언어 설정을 쓸 때 레지스트리 심볼릭 링크를 따라가지 않도록 했습니다.
- 다른 로컬 사용자가 전역 객체를 선점해 앱 실행이나 설치를 막을 수 있던 경로를 제거했습니다.
- 배포 소스·원격 태그 일치 검사와 GitHub Actions 권한·자격증명 범위를 강화했습니다.

**변경된 사용 조건:** Windows 10 1607 이상 / Windows 11 x64. Windows 작업 관리자 대체 기능을 쓰려면 **Setup으로 먼저 설치**하세요. 포터블의 프로세스·성능·시작 앱·서비스 기능은 계속 사용할 수 있습니다.

자동 회귀 테스트 74개, 배포 소스 검증 테스트 16개 및 정적 검사를 통과했습니다. 실제 관리자 설치·제거와 보안 화면 실행은 별도 수동 검증 범위입니다.

**Setup-x64.exe**는 설치용, **Portable-x64.exe**는 바로 실행하는 파일입니다. 앱·설치·제거 프로그램은 Azure Artifact Signing / **HARDT**로 서명하고 타임스탬프를 검증했습니다. 체크섬은 `SHA256SUMS.txt`, 상세 검토 내용과 검증 한계는 [보안 검토](https://github.com/Hardt-LLC/FeatherTaskManager/blob/v2026.9.2/SECURITY.md)를 참고하세요.

### English

Security update addressing four locally exploitable issues: portable source-file substitution during elevated copying, adjacent static DLL loading, registry-link redirection of startup/preference writes, and public global-object squatting that could block launches or installation.

Task Manager replacement now requires a protected installation made with Setup. Portable process management remains available. Static DLL search is restricted to System32; the minimum supported OS is Windows 10 version 1607 or Windows 11, x64. Release-source, remote-tag and workflow credential checks are also hardened.

App, installer and embedded uninstaller are Azure Artifact Signing signed by **HARDT** and timestamped. See `SHA256SUMS.txt` and [the security review](https://github.com/Hardt-LLC/FeatherTaskManager/blob/v2026.9.2/SECURITY.md) for scope and remaining verification limits.
