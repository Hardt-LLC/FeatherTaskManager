## Feather Task Manager 2026.9.4

성능 그래프 끊김을 고치고, 관리자 권한 기본 실행 설정과 Microsoft Store 배포 준비를 더했습니다.

- **성능 그래프 끊김 수정:** 시작 앱·서비스·설정 화면에 있는 동안에도 성능 기록을 계속 수집합니다. 다른 화면에 다녀와도 그래프가 이어집니다. 일시정지·최소화·확인 창이 열린 동안에는 이전처럼 수집을 멈추고 그 구간을 끊김으로 표시합니다.
- **설정 → 창 → 항상 관리자 권한으로 실행:** 켜 두면 **설치된 Feather**가 시작할 때마다 Windows UAC로 승인을 요청합니다. 프로세스별 네트워크와 전체 좀비 검사에 필요합니다. 포터블 EXE는 자동으로 올리지 않으며, ⋯ → 관리자 권한으로 실행은 그대로 쓸 수 있습니다. UAC를 거절하면 일반 권한으로 계속 실행합니다.
- 관리자 권한 창에서도 탐색기를 다시 시작한 뒤 트레이 아이콘이 돌아옵니다.
- 제거하면 제거 프로그램을 실행한 계정의 Feather 환경설정(`HKCU\Software\FeatherTask`)도 지웁니다. 레지스트리 링크는 따라가지 않습니다.
- 설치 정보와 실행 파일의 게시자 표기를 서명 인증서와 같은 **HARDT**로 맞췄습니다.
- [개인정보 처리방침](https://github.com/Hardt-LLC/FeatherTaskManager/blob/v2026.9.4/PRIVACY.md)을 추가했습니다. Feather는 개인정보를 수집·전송하지 않으며 인터넷에 연결하지 않습니다.

자동 검사 **305개 통과**, 형식·Clippy·배포 스크립트 검사를 통과했습니다. 관리자 권한 경로와 실제 설치·제거는 별도 수동 확인 범위입니다.

**Setup-x64.exe**는 설치용, **Portable-x64.exe**는 바로 실행하는 파일입니다. 앱·설치·제거 프로그램은 Azure Artifact Signing / **HARDT**로 서명하고 타임스탬프를 검증했습니다. 체크섬은 `SHA256SUMS.txt`를 참고하세요.

### English

- **Performance history no longer breaks** when you visit Startup apps, Services or Settings and come back; sampling continues on every page and still pauses (with an honest gap) while paused, minimized or behind a dialog.
- **Settings → Window → Always run as administrator:** the installed Feather asks for administrator approval (UAC) at every start, for per-process network and full zombie scans. Portable copies are never elevated automatically; ⋯ → Run as administrator still works. Declining UAC keeps Feather running normally.
- The tray icon of an elevated window comes back after Explorer restarts.
- Uninstall removes the running account's Feather preferences (`HKCU\Software\FeatherTask`) without following registry links.
- The installer and executable publisher is now **HARDT**, matching the signing certificate.
- Added a [privacy policy](https://github.com/Hardt-LLC/FeatherTaskManager/blob/v2026.9.4/PRIVACY.md): Feather collects and transmits no personal information and makes no internet connections.

305 automated tests passed, plus format, Clippy and release-script checks. Administrator-only paths and real install/uninstall remain manual verification scope.

App, installer and embedded uninstaller are Azure Artifact Signing signed by **HARDT** and timestamped. See `SHA256SUMS.txt`.
