## Feather Task Manager 2026.9.3 — 새 디자인, 하드웨어 정보, Nuclear Zombie

디자인 레퍼런스에 맞춰 화면 전체를 다시 그렸고 프로세스별 GPU, 장치 모델·GPU 온도, 메모리 정리 도구를 추가했습니다.

**새 디자인**
- 로고·검색·최소화/최대화/닫기를 하나의 44px 제목 표시줄로 통합했습니다. Windows 11 스냅 레이아웃을 지원합니다.
- 기본 Windows 컨트롤 대신 직접 그린 표·버튼·선택 상자·메뉴·확인 창·알림을 사용합니다. 밝게/어둡게 테마 색상을 레퍼런스에 맞췄습니다.
- 픽셀 단위 부드러운 스크롤, 자동으로 숨는 오버레이 스크롤바, 호버·스위치·펼치기·탐색 막대 애니메이션을 추가했습니다. 애니메이션 중에만 타이머를 쓰며 Windows의 애니메이션 효과 설정을 따릅니다.
- **앱별 그룹**: 앱마다 펼칠 수 있는 계층과 합계를 표시합니다. Windows 프로세스는 이름이 아닌 실행 파일 경로로 분류합니다.
- 프로세스·시작 앱·서비스 표는 스크린 리더(MSAA)를 지원합니다.

**하드웨어 정보**
- 프로세스별 GPU 사용률(가장 바쁜 엔진 기준)을 표시합니다. 프로세스별 네트워크는 **관리자 권한으로 실행할 때만** ETW로 측정하며, 일반 권한에서는 "—"와 안내를 표시합니다.
- 성능: GPU 모델명·전용 메모리·드라이버·온도·팬·전력, 디스크 모델·종류(NVMe/SATA/USB)·용량, 메모리 속도·슬롯·형식, 네트워크 어댑터 모델·링크 속도, CPU 기본 속도·캐시·가상화. 연결되지 않은 어댑터와 소프트웨어 GPU는 숨깁니다.
- CPU 온도는 커널 드라이버 없이 안전하게 읽을 방법이 없어 표시하지 않습니다. ACPI 열 영역이 있으면 그 이름으로만 표시합니다.

**Nuclear Zombie** (프로세스 페이지)
- 작업 집합 정리, 대기 캐시 비우기·수정된 페이지 플러시(관리자), **좀비 프로세스 찾기**(이미 종료됐지만 다른 프로그램이 핸들을 붙잡고 있는 프로세스)를 한 창에서 실행하고 측정된 전후 값과 붙잡고 있는 프로그램 목록을 확인합니다.
- 다른 프로그램의 핸들을 닫거나 프로세스를 자동으로 종료하지 않습니다. 붙잡고 있는 프로그램 종료는 기존 확인 창을 거칩니다.
- 관리자 정리는 설치된 동일 빌드의 도우미만 UAC로 실행합니다. 효율 모드는 ⋯ 메뉴와 오른쪽 클릭 메뉴에 있습니다.

**보안** ([검토 내용](https://github.com/Hardt-LLC/FeatherTaskManager/blob/v2026.9.3/SECURITY.md))
- 실행 중 불러오는 DLL도 System32에서만 찾도록 제한했습니다. 포터블 EXE 옆(예: 다운로드 폴더)에 놓인 DLL이 Feather 안에서 실행될 수 있던 경로를 막았습니다(FTM-2026-05).
- 메모리 정리 특권 즉시 복원, 관리자 도우미 인수 엄격화, 진단 출력 파일의 링크 따라가기 차단, 네트워크 ETW 이벤트 제공자 확인을 추가했습니다(FTM-2026-06~09).

자동 검사 **290개 통과**, 형식·Clippy·배포 스크립트 검사를 통과했습니다. 관리자 권한 경로(프로세스별 네트워크, 메모리 목록 정리)와 실제 설치·제거는 별도 수동 확인 범위입니다.

**Setup-x64.exe**는 설치용, **Portable-x64.exe**는 바로 실행하는 파일입니다. 앱·설치·제거 프로그램은 Azure Artifact Signing / **HARDT**로 서명하고 타임스탬프를 검증했습니다. 체크섬은 `SHA256SUMS.txt`를 참고하세요.

### English

A full redesign that follows the design reference, plus per-process GPU, device models and GPU temperature, and a memory cleanup tool.

- **Design:** one 44 px title bar with the logo, search and window buttons (Snap Layouts supported); custom-drawn tables, buttons, selects, menus, dialogs and toasts with the reference light/dark colors; pixel-smooth scrolling, auto-hiding overlay scrollbars and short animations that run only while something moves and respect the Windows animation setting; collapsible per-app groups; MSAA screen-reader support for the tables.
- **Hardware:** per-process GPU (busiest engine); per-process network measured through ETW **only when running as administrator** (otherwise "—" with a hint); GPU model, dedicated memory, driver, temperature, fan and power; disk model, bus and capacity; memory speed, slots and form factor; network adapter model and link speed; CPU base speed, caches and virtualization. CPU temperature is not shown because there is no safe user-mode source.
- **Nuclear Zombie** (Processes page): trim working sets, clear the standby cache / flush modified pages (administrator), and find zombie processes (exited processes still held open by another program), with measured before/after values in one panel. It never closes handles inside other programs or ends processes on its own. Efficiency mode moved to the ⋯ and context menus.
- **Security:** DLLs loaded at run time are now also restricted to System32, closing a path where a DLL placed next to the portable EXE (for example in Downloads) could run inside Feather (FTM-2026-05). The memory-list privilege is restored right after use, helper arguments are strict, diagnostic output refuses links, and network ETW events are checked by provider (FTM-2026-06 to 09). See [the security review](https://github.com/Hardt-LLC/FeatherTaskManager/blob/v2026.9.3/SECURITY.md).

290 automated tests passed, plus format, Clippy and release-script checks. Administrator-only paths (per-process network, memory list purge) and real install/uninstall remain manual verification scope.

App, installer and embedded uninstaller are Azure Artifact Signing signed by **HARDT** and timestamped. See `SHA256SUMS.txt`.
