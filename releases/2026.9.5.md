## Feather Task Manager 2026.9.5

Windows 리소스 모니터를 대신하는 내장 리소스 모니터와, 프로세스 열 선택·새 작업 실행·성능 장치 순서 바꾸기를 더했습니다.

- **내장 리소스 모니터:** 성능 → 리소스 모니터가 Windows resmon 대신 Feather 창을 엽니다. 개요·CPU·메모리·디스크·네트워크 5개 탭, 공통 프로세스 필터, 모듈, 연결·수신 포트 목록, 확인 후 프로세스 끝내기를 제공합니다. 파일·네트워크 상세 추적(관리자 권한)은 기본 꺼짐이고, 창을 닫거나 일시정지·최소화하면 멈춥니다. 비용과 측정 범위는 [RESOURCE_MONITOR.md](https://github.com/Hardt-LLC/FeatherTaskManager/blob/v2026.9.5/RESOURCE_MONITOR.md)를 참고하세요.
- **프로세스 열 선택:** 열 머리글 오른쪽 클릭이나 ⋯ → 열 선택…(`Ctrl+Shift+C`)으로 사용자·세션·명령줄·상태·CPU 시간·핸들·GPU 메모리 등 최대 18개 열을 표시합니다. 머리글을 끌어 순서를, 경계를 끌어 너비를 바꾸고 배치는 저장됩니다.
- **새 작업 실행:** 프로그램과 인수를 따로 입력하고, 필요하면 UAC를 거쳐 관리자 권한으로 실행합니다. 메뉴에서 앱 창으로 전환하거나, 확인 후 Windows 탐색기를 다시 시작할 수 있습니다.
- **성능 장치 순서:** 성능 화면의 장치를 끌거나 `Alt+↑`/`Alt+↓`로 원하는 순서로 바꾸면 저장됩니다.
- **프로세스 ↔ 서비스 이동:** 프로세스에서 서비스로, 서비스에서 실행 중인 프로세스로 바로 이동하고 파일 속성을 열 수 있습니다. `pid:1234`로 정확한 PID를 찾습니다. 관리자 권한 없이도 서비스 호스트로 이동합니다.
- **펌웨어 온도 영역:** 펌웨어가 제공하는 ACPI 열 영역 온도를 영역 이름으로 보여 줍니다. CPU 온도로 표시하지 않으며, 드라이버를 설치하지 않습니다.
- [개인정보 처리방침](https://github.com/Hardt-LLC/FeatherTaskManager/blob/v2026.9.5/PRIVACY.md)을 새 기능(연결 목록, 모듈 경로, 명령줄, 선택형 추적)에 맞게 고쳤습니다. 여전히 어떤 정보도 수집하거나 전송하지 않습니다.

자동 검사 **318개 통과**, 형식·Clippy·배포 스크립트 검사를 통과했습니다. 이 검증 PC는 150% 배율이라, 100% 기준 픽셀 값을 쓰는 UI 배치 검사 15개가 실패합니다. 2026.9.4 소스에서도 같은 15개가 똑같이 실패하므로 이번 변경과는 무관하며, 따로 고칩니다. 관리자 권한 경로(관리자 권한 새 작업, 탐색기 다시 시작, 관리자 파일·네트워크 추적)와 실제 설치·제거는 별도 수동 확인 범위입니다.

**Setup-x64.exe**는 설치용, **Portable-x64.exe**는 바로 실행하는 파일입니다. 앱·설치·제거 프로그램은 Azure Artifact Signing / **HARDT**로 서명하고 타임스탬프를 검증했습니다. 체크섬은 `SHA256SUMS.txt`를 참고하세요.

### English

- **Built-in Resource Monitor:** Performance → Resource Monitor opens Feather's own window instead of Windows resmon: Overview, CPU, Memory, Disk and Network pages, shared process filters, modules, connection and listening-port tables, and confirmed process termination. Detailed file and network tracing (administrator) is off by default and stops when the window is closed, paused or minimized. See [RESOURCE_MONITOR.md](https://github.com/Hardt-LLC/FeatherTaskManager/blob/v2026.9.5/RESOURCE_MONITOR.md) for costs and measurement limits.
- **Process columns:** right-click a column header or use ⋯ → Choose columns… (`Ctrl+Shift+C`) to show up to 18 columns, such as user, session, command line, status, CPU time, handles and GPU memory. Drag headers to reorder and edges to resize; the layout is saved.
- **Run new task:** enter a program and its arguments separately, optionally running it as administrator through UAC. The menus can also switch to an app's window and, after confirmation, restart Windows Explorer.
- **Performance device order:** drag devices on the Performance page, or press `Alt+↑`/`Alt+↓`, to keep them in your order.
- **Process ↔ service navigation:** jump from a process to its services and from a service to its running process, or open a file's Properties. Search `pid:1234` for an exact PID. Service hosts resolve without administrator rights.
- **Firmware thermal zones:** ACPI thermal zone temperatures from the firmware are shown by zone name, never as CPU temperature, and no driver is installed.
- The [privacy policy](https://github.com/Hardt-LLC/FeatherTaskManager/blob/v2026.9.5/PRIVACY.md) now covers the new data shown on screen (connections, module paths, command lines, opt-in tracing). Feather still collects and transmits nothing.

318 automated tests passed, plus format, Clippy and release-script checks. This validation PC runs at 150% scaling, where 15 UI layout tests that hard-code 100% pixel values fail; the same 15 fail identically on the 2026.9.4 source, so they are unrelated to this release and will be fixed separately. Administrator-only paths (elevated Run new task, Explorer restart, elevated file and network tracing) and real install/uninstall remain manual verification scope.

App, installer and embedded uninstaller are Azure Artifact Signing signed by **HARDT** and timestamped. See `SHA256SUMS.txt`.
